## 2026-11-11：第六區左右並列晶體模型

依使用者核可的左右分欄示意，左側沿用同一個連續實驗場景，右側新增同步的硫酸銅局部晶體模型；桌機並排、窄螢幕直向排列。模型以 Cu²⁺、SO₄²⁻及H₂O球棒圖表現五水合硫酸銅的局部配位關係（四個配位水、兩個軸向硫酸根氧及一個氫鍵連結的晶格水），加熱時水分子逐步離開、晶格重排，再以無水物晶格顯示產物；水合時反向更新。粒子圖形為教學局部示意，非按晶體學座標逐原子重建，也不依比例。

結構關係依[IUCr五水合硫酸銅X光／中子繞射研究](https://journals.iucr.org/m/issues/2022/01/00/fs5200/)及[硫酸銅不同水合物的晶體結構研究](https://opus.uleth.ca/items/4a78691f-b4d7-4a88-a744-b18cd8355c7d)整理。熱脫水可能經過較低水合物；模型只呈現前後狀態及逐步失水；動畫中段的簡化晶格用來表示重排，不代表某一種固定中間水合物或所有條件下相同的反應路徑。

依最新示意圖回看第六區時，桌機畫面調整為實驗動畫／晶體模型左右對照。實驗動畫主實驗場景改用依原底圖生成的玻璃罩照片；加熱時顯示玻璃罩，準備加水時與無罩底圖平順交接。另加入冷凝水及從四階段實驗圖裁切的三格照片摘要（藍色含水物→加熱變白→加水復藍）；主畫面仍是單一連續的器材動畫，三格圖只作反應結果摘要。冷卻並準備加水時，玻璃罩上移讓出滴管位置。右側模型同屏展示含水結構、脫水重排、無水物與水，使用顏色圖例及雙向能量提示；模型仍以可讀的局部結構示意呈現，不宣稱精確晶體座標。

`chem-bench-covered.png` 以原實驗空台底圖生成，只新增與其角度、比例相符的玻璃罩；保留同一個空玻璃皿、網架及暖色背景，未添加樣品或火焰。主場景的藍白樣品、燈芯火焰、冷凝水珠、滴管與水滴仍由原動畫層同步控制。
