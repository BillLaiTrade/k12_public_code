# 相機單元小測

相機任務是獨立的小測與狀態，不依賴投影機。相機與凸透鏡固定；學生移動花朵改變物距，並移動感光元件調整像距。共用光軌呈現感光元件、固定鏡頭、花朵與兩側 F、2F；可直接拖動花朵或感光元件的標籤或圓點，亦可選取後點選尺面或按鈕及方向鍵微調，綠色尺段為可移動範圍，焦距刻度與細刻度用來判讀各器材的位置。

`camera-optics.mjs` 重用薄透鏡模型和 `rayAt`；預覽呈現感光元件上的倒立影像，大小隨截距變化，模糊依有限孔徑的光線擴散近似。清楚、縮小及完整的條件共同決定結果：完整以預覽可見範圍和同一影像比例判定。兩組輔助光線從花朵上下兩個不同物點出發，各自計算在感光元件處的截距。模型不模擬相機螢幕的電子轉正或鏡頭像差。

執行 `node --test tests/unit-4.4-camera-optics.test.mjs tests/unit-4.4-camera-quiz.test.cjs` 驗證光學、光路、對焦、介面與獨立狀態。

`camera-model.mjs` 建立真實立體的相機剖面、旋轉對稱凸透鏡、感光元件、花朵及輔助光路。所有光線與器材共處同一三維座標，旋轉視角時同步投影；拖曳與滾輪只改變視角，重設視角不改變器材。3D 無法使用時，原剖面插畫作為備用，保留同一組成像判定及距離控制。

花朵的正面固定朝向相機鏡頭；旋轉觀察視角只改變外部觀看方向，感光元件所見影像及花朵朝向不隨之旋轉。

輔助光路在載入及重新挑戰時預設顯示，可手動隱藏。焦點標記以固定鏡頭位置計算；移動感光元件不改變焦點。

相機場景高度隨視窗高度調整，視角操作收在場景內；1280×720、1366×768、1440×900 及 1024×768 筆電視窗可同時呈現場景、光軌與操作按鈕。

任務前說明感光元件接收影像並將光轉換成電訊號，並引導先以 F、2F 判斷花朵位置，再調整感光元件；模型以移動感光元件簡化對焦。

感光元件可移至鏡頭與 F 之間；此時仍會接收光線，預覽模糊程度與光線截距依同一組焦距與位置計算。最小距離保留鏡頭與元件之間的空間。
